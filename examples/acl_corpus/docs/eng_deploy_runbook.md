# 工程部发布手册

本文是为权限测试编写的合成示例文档，仅工程部可见。标记：ACLCANARY-ENG-4821。

## 发布前检查

工程部发布前要完成三项检查：全部自动化测试通过、变更说明经过同行评审、回滚脚本在预发环境演练成功。缺少任何一项都不得进入发布窗口。

## 发布窗口

工程部的常规发布窗口是每周二和周四的下午两点到四点。紧急修复可以申请临时窗口，需要值班负责人批准，并在发布后二十四小时内补写复盘。

## 回滚预算

每次发布预留十五分钟回滚预算。发布后监控指标超过阈值时，值班工程师应立即回滚，而不是在线排查。代号为 ACLCANARY-ENG-4821 的演练脚本保存在内部仓库。
